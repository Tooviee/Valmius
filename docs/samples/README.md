# Sample output

Documents generated by Valmius for **Ledgerline**, a fictional 30-person SaaS company used for the manual checks during the build. Every person, law firm and phone number in these files is fictional. The insurer named in the plan (At-Bay) is a real company used as a realistic example of a cyber insurer; Ledgerline has no relationship with it.

| File | What it is | How it was produced |
|---|---|---|
| `ledgerline-ir-plan.pdf` | 16-page incident response plan, version 2, approved | 15-question questionnaire, ten model-written sections inside a fixed outline, notification matrix built in code, exported from the plan page |
| `ledgerline-after-action-report.pdf` | 5-page after-action report from a cloud-credential drill | Facts assembled from the exercise record (attendance, sign-offs, server-stamped decisions, findings, control mapping); the model wrote only the five narrative sections |

Both files were produced by the deployed application at valmius.app with the real model (`claude-sonnet-5-5`), not by the test mock.
